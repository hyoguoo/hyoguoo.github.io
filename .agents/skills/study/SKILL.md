# /study - 문서 기반 학습 및 보강 사이클

## Triggers

- 사용자가 특정 주제나 카테고리에 대해 복습, 학습, 또는 공부를 요청할 때
- 문서 개선과 학습을 동시에 진행하고 싶어 할 때

## 동작 방식 (학습 사이클)

1. **문서 분석 및 빈틈 파악**
    - 사용자가 학습하려는 주제와 관련된 기존 마크다운 문서들을 읽고 분석한다.
    - 기존 문서에서 설명이 부족하거나 누락된 중요한 실무/이론적 개념(Edge Case, 주의점, 내부 동작 원리 등)을 찾아낸다.

2. **학습 질문 제시**
    - 파악한 빈틈을 바탕으로 사용자에게 질문을 던진다.
    - 이때 '면접관' 같은 압박적인 페르소나를 쓰지 않고, 순수하게 '학습과 복습'을 돕는 파트너의 톤앤매너를 유지한다.
    - 예시: "현재 문서에 OOO에 대한 설명은 잘 정리되어 있습니다. 그렇다면 실무에서 자주 발생하는 XXX 상황에서는 어떻게 동작할까요? 이 부분을 한 번 복습해 보면 좋을 것 같습니다."

3. **사용자 답변 및 피드백**
    - 사용자가 답변(또는 모른다고 답변)하면, 정확한 개념과 실무적 주의점 등을 피드백하며 지식을 정리해 준다.

4. **문서 보강 (작성 규칙 철저 준수)**
    - 논의된 내용을 바탕으로 기존 문서의 적절한 위치를 찾아 내용을 즉시 보충(수정)한다.
    - 문서 업데이트 시 **반드시 `/writing` 스킬의 문서 콘텐츠 작성 컨벤션을 엄격하게 준수**해야 한다.
        - 볼드체(`**`) 절대 금지
        - 명사형 또는 `~다.` 종결
        - 한 단락 1문장 + 세부 사항 리스트화 등
