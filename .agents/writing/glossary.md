# blog 저장소 용어표

이 저장소의 글에 쓰는 표기다. 다른 저장소의 용어표와 다르면 이 표를 따른다(글이 실리는 저장소가 우선).

## 표기

| 의미 | 쓰는 표기 | 쓰지 않는 표기 |
|---|---|---|
| worker | 워커 | Worker |
| test | 테스트 | 시험 |
| DB connection | DB 커넥션 | DB 연결 |
| 성능 측정에서 처리 속도가 유입을 따라가는 상태 / 못 따라가는 상태 | 안정 처리 / 적체 누적 | 따라잡음 / 계속 쌓임 |
